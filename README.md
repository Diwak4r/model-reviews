# Model Reviews by @Norwakar

> I test frontier AI models so you don't have to. Raw benchmarks, honest takes.

Every review runs the **same 5 tests, the same prompts, zero retries**, so models can be compared fairly over time. Each folder holds the exact prompts, the raw outputs and the scorecard.

## The 5 tests
1. **Wow output**: the most impressive single thing the model can make from one prompt.
2. **1-minute showreel**: a 60-second video or motion piece made by or about the model's outputs.
3. **Single-HTML 3D world**: one self-contained HTML file, explorable 3D, no assets.
4. **SVG attention-hijack**: one SVG that stops the scroll.
5. **Technical test**: one hard, measurable task that sets where the model sits.

Plus a **scorecard** against the closest rival, and a **verdict**.

## Rules
- One prompt per test, zero retries, default settings unless noted.
- Same prompt goes to the rival model.
- Cost and time are recorded for each run.
- Outputs are committed as-is, with no hand edits.
